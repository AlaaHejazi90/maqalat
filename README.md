# دليل التشغيل: روابط مقالات عبدالعزيز

## وش يسوي هالمشروع

| الصفحة | وش هي | قوقل |
|---|---|---|
| `/` | صفحة فيها كل مقالاته، وكل مقالة تودّي لسبق مباشرة | تظهر في قوقل (بوابة إضافية للمقالات) |
| `/a/اسم-المقالة?src=wa` | رابط المشاركة: معاينة بالعنوان والصورة اللي تختارها، وتحويل فوري لمقالة سبق | مخفية (noindex) |
| `/links` | صفحتك أنت: رابط لكل قناة + منشور جاهز تنسخه | مخفية |

## الإعداد (مرة وحدة، ~20 دقيقة)

### 1) العدّاد: GoatCounter (مجاني، 3 دقائق)
1. ادخل goatcounter.com واضغط **Sign up**.
2. في خانة **Code** اكتب اسم قصير بالإنجليزي، مثلاً `omran`.
3. افتح `config.json` وحط الاسم في `"goatcounter": "omran"`.
4. الإحصائيات بتكون على `omran.goatcounter.com`، وكل سطر شكله `/sudair-solar/wa` يعني: مقالة سدير، من واتساب.

### 2) GitHub (مكان الملفات، 5 دقائق)
1. سوّ حساب على github.com.
2. اضغط **+** فوق ← **New repository** ← الاسم `maqalat` ← **Create repository**.
3. اضغط **uploading an existing file** واسحب كل محتويات المجلد هنا (الملفات ومجلد images) ← **Commit changes**.

### 3) Vercel (النشر، 5 دقائق)
1. ادخل vercel.com ← **Sign Up** ← **Continue with GitHub**.
2. **Add New… ← Project** ← اختر `maqalat` ← **Import** ← **Deploy** (لا تغيّر أي إعداد).
3. بعد دقيقة يعطيك رابط مثل `maqalat.vercel.app`. افتح `maqalat.vercel.app/links`.

> تبي Netlify بدال Vercel؟ نفس الخطوات: **Add new site ← Import from GitHub**، والإعدادات جاهزة في `netlify.toml`.
> عندك دومين خاص؟ حطه في `siteUrl` داخل `config.json`، واربطه من إعدادات Vercel (Settings ← Domains).

## مع كل مقالة جديدة (~3 دقائق)

1. في GitHub افتح `articles.json` ← أيقونة القلم ✏️.
2. انسخ هالقالب وحطه **بعد أول قوس `[`** مباشرة:

```json
  {
    "slug": "اسم-انجليزي-قصير",
    "url": "رابط المقالة في سبق",
    "title": "عنوان المعاينة",
    "description": "وصف قصير يطلع تحت العنوان",
    "image": "رابط الصورة أو images/اسم-الصورة.jpg",
    "date": "2026-10-17",
    "hook": "جملة تشويق تنحط أول المنشور"
  },
```

3. **Commit changes**. خلال 30 ثانية Vercel يحدّث الموقع تلقائياً.
4. افتح `/links`، ولكل قناة اضغط **نسخ المنشور** والصقه.

**قواعد سريعة:**
- `slug` حروف إنجليزية صغيرة وأرقام وشرطة فقط، مثل `sudair-solar`.
- كل مقالة بين `{ }` وبعدها فاصلة `,`، إلا آخر وحدة ما بعدها فاصلة.
- إذا فيه غلط في الملف، Vercel يوقف التحديث ويكتب لك وين الغلط (Deployments ← آخر واحد). الموقع القديم يظل شغّال.

## أهم نصيحة: الصورة

البطاقة اللي يصممها عبدالعزيز لكل مقالة (صورته والعنوان والاقتباس) **حطها هي صورة المعاينة**:
1. في GitHub ادخل مجلد `images` ← **Add file ← Upload files** ← ارفع الصورة.
2. في `articles.json` اكتب `"image": "images/اسم-الصورة.jpg"`.

كذا لما ينشر الرابط، تطلع البطاقة كمعاينة للرابط، **وأي ضغطة عليها تفتح المقالة في سبق**. اليوم الضغط على الصورة المرفوعة ما يودّي لأي مكان.

- المقاس الأفضل 1200×630، بصيغة JPG أو PNG. بعض التطبيقات ما تعرض صيغة webp.
- اختبر المعاينة قبل النشر: أرسل الرابط لنفسك في واتساب، واستخدم LinkedIn Post Inspector للينكدإن.
- إذا غيّرت الصورة بعد ما شاركت الرابط، واتساب ولينكدإن يحفظون المعاينة القديمة فترة. أضف `&v=2` لآخر الرابط عشان يقرونها من جديد.

## ملاحظات
- العدّاد يحسب **الضغطات على روابطك**، مو كل مشاهدات المقالة في سبق.
- لما واتساب و X يفتحون الرابط آلياً عشان يسوون المعاينة، هالفتح ما ينحسب ضغطة، وما ينحسب مشاهدة في سبق.
